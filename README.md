# NotebookLM Knowledge Base

A comprehensive knowledge base about Google NotebookLM, including tutorials, use cases, and historical development timeline.

[中文文档](./README_zh.md)

## About This Project

This is a community-driven knowledge base for Google NotebookLM, featuring:

- **Comprehensive Tutorials** - Step-by-step guides for using NotebookLM
- **Real-world Use Cases** - Examples from various domains
- **Historical Timeline** - Development history and feature evolution
- **Multi-language Support** - Available in English, Simplified Chinese, and Traditional Chinese
- **Modern Documentation** - Built with VitePress 2.0 and Vue 3.5

## Quick Start

### Development

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview
```

## What is NotebookLM?

NotebookLM is Google's AI-powered note-taking and research assistant that helps you:
- Understand complex documents and sources
- Generate summaries and insights
- Ask questions about your content
- Create study guides and audio overviews
- Collaborate with others on research

This knowledge base contains everything you need to master NotebookLM.
