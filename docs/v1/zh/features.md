# NotebookLM 核心功能

NotebookLM 提供了一系列强大的 AI 驱动功能，帮助你更好地理解和利用文档资料。

## 文档管理

### 多格式支持

NotebookLM 支持导入多种类型的文档：

| 格式类型 | 具体格式 | 说明 |
|---------|---------|------|
| 文档文件 | PDF | 最常用的文档格式 |
| | Google 文档 | 自动同步更新 |
| | Google 幻灯片 | 演示文稿支持 |
| | TXT | 纯文本文件 |
| | Markdown | 支持格式化文本 |
| 网页内容 | URL 链接 | 自动提取网页内容 |
| | 复制粘贴 | 快速添加文本 |
| 音频文件 | 音频录音 | 实验性功能 |

### 来源管理

- **组织来源** - 为每个来源添加标签和说明
- **查看来源** - 快速浏览文档内容
- **编辑来源** - 更新或修改已上传的文档
- **删除来源** - 移除不需要的文档
- **来源限制** - 每个笔记本最多 50 个来源

::: tip 最佳实践
将相关的文档放在同一个笔记本中，这样 AI 可以跨文档分析和关联信息。
:::

## AI 对话与问答

### 智能问答

NotebookLM 的核心功能是基于你的文档进行智能问答：

**问题类型：**

1. **事实性问题**
   - "文档中提到的关键数据是什么？"
   - "作者的主要观点是什么？"

2. **分析性问题**
   - "比较这两个文档的观点差异"
   - "这个理论的优缺点是什么？"

3. **总结性问题**
   - "总结这篇文章的主要内容"
   - "列出关键要点"

4. **创造性问题**
   - "基于这些文档，给我一些项目想法"
   - "如何将这些概念应用到实际中？"

### 引用和溯源

NotebookLM 的一大特色是**始终引用来源**：

- 每个回答都会标注信息来源
- 点击引用可以查看原文段落
- 确保信息的可追溯性和准确性
- 避免 AI 幻觉（编造信息）

::: warning 重要
如果 NotebookLM 在你的文档中找不到答案，它会明确告诉你，而不是编造信息。
:::

### 对话历史

- 自动保存所有对话
- 可以查看和搜索历史对话
- 继续之前的讨论
- 导出对话记录

## 自动生成内容

### 摘要生成

NotebookLM 可以自动生成文档摘要：

**摘要类型：**

- **执行摘要** - 简短的核心要点
- **详细摘要** - 全面的内容概览
- **章节摘要** - 按章节分别总结
- **对比摘要** - 多个文档的比较

**使用场景：**

- 快速了解长文档内容
- 准备会议和演讲
- 提取关键信息
- 节省阅读时间

### 学习指南

自动生成学习材料，包括：

1. **关键术语词汇表**
   - 重要概念定义
   - 专业术语解释

2. **复习问题**
   - 理解性问题
   - 应用性问题
   - 批判性思考问题

3. **学习重点**
   - 必须掌握的概念
   - 重要的知识点

4. **练习建议**
   - 如何深入学习
   - 相关练习推荐

::: tip 学生福音
学习指南功能特别适合学生复习考试和准备课程。
:::

### 常见问题解答（FAQ）

基于文档自动生成 FAQ：

- 识别常见主题和问题
- 提供清晰的答案
- 组织逻辑结构
- 便于快速查询

### 时间线生成

将文档内容组织成时间线：

- 历史事件排序
- 项目进展追踪
- 发展历程梳理
- 可视化时间关系

## 音频概述（Audio Overview）

这是 NotebookLM 最具创新性的功能之一！

### 功能介绍

音频概述将你的文档转换为**播客式的 AI 对话**：

- 两个 AI 主持人进行对话
- 讨论文档的主要内容
- 自然流畅的对话风格
- 帮助理解复杂概念

### 使用场景

**适合的情况：**

- 通勤途中听文档概述
- 锻炼时学习内容
- 换个方式理解材料
- 多任务处理时学习

**特别适用于：**

- 长篇学术论文
- 复杂技术文档
- 多个文档的综合理解
- 需要反复理解的内容

### 功能特点

- **自动生成** - 一键创建音频
- **多语言支持** - 支持多种语言
- **自然对话** - 不是机械朗读
- **可下载** - 保存为音频文件
- **时长控制** - 根据内容自动调整（通常 5-10 分钟）

::: tip 创新功能
音频概述让学习变得更加灵活，你可以在任何场景下"听"你的文档！
:::

### 限制说明

- 每次生成需要一定时间
- 音频质量取决于文档质量
- 不能替代详细阅读
- 作为补充学习工具使用

## 笔记和批注

### 创建笔记

在使用 NotebookLM 的过程中，你可以：

- **保存 AI 回答** - 将有价值的回答保存为笔记
- **手动添加笔记** - 记录自己的想法和理解
- **添加批注** - 对文档内容进行标注
- **创建待办事项** - 记录需要完成的任务

### 笔记管理

- **分类整理** - 使用标签和文件夹
- **搜索笔记** - 快速查找信息
- **链接笔记** - 建立笔记之间的关联
- **导出笔记** - 导出为其他格式

## 协作功能

### 共享笔记本

NotebookLM 支持团队协作：

**共享选项：**

1. **查看权限**
   - 只能查看内容
   - 不能编辑和添加

2. **编辑权限**
   - 可以添加来源
   - 可以创建笔记
   - 可以使用所有功能

3. **管理权限**
   - 包含编辑权限
   - 可以管理协作者
   - 可以删除笔记本

### 协作场景

- **团队研究** - 共同分析资料
- **课程学习** - 小组协作学习
- **项目管理** - 团队知识共享
- **内容创作** - 协作整理素材

::: tip 协作建议
建立清晰的命名规范和组织结构，让团队成员容易找到和使用资料。
:::

## 自定义和高级功能

### 自定义指令

你可以给 NotebookLM 设定特定的行为方式：

- 指定输出格式（列表、表格、段落）
- 设定回答的详细程度
- 要求特定的分析角度
- 自定义专业术语处理

### 来源选择

在提问时，你可以：

- 选择特定的来源进行分析
- 排除某些来源
- 对比不同来源的信息
- 跨来源综合分析

### 导出功能

- **导出笔记** - 保存为文档
- **导出对话** - 保存问答历史
- **导出音频** - 下载音频概述
- **打印友好** - 适合打印的格式

## 隐私和安全

### 数据保护

- 文档存储在 Google 云端
- 符合 Google 隐私政策
- 数据加密传输和存储
- 你完全控制自己的数据

### 访问控制

- 只有授权用户可以访问
- 可以随时撤销共享
- 可以删除文档和笔记本
- 符合 GDPR 等隐私法规

::: warning 注意
不要上传包含极其敏感或机密信息的文档，除非你完全理解和接受 Google 的隐私政策。
:::

## 限制和注意事项

### 使用限制

- 每个笔记本最多 50 个来源
- 单个文件最大 500,000 字
- 需要稳定的网络连接
- 某些格式可能不完全支持

### AI 的局限性

虽然 NotebookLM 很强大，但仍需注意：

- **不是万能的** - 对于模糊或复杂的问题可能需要多次提问
- **依赖文档质量** - 输入文档的质量影响输出结果
- **需要人工验证** - 重要决策应该验证 AI 的回答
- **理解能力有限** - 某些专业领域可能理解不够深入

## 最佳使用建议

1. **从小开始** - 先用少量文档测试功能
2. **清晰提问** - 问题越具体，回答越准确
3. **验证信息** - 检查引用的准确性
4. **善用功能** - 尝试不同的功能组合
5. **持续学习** - NotebookLM 在不断更新改进
