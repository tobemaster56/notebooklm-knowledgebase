# 快速开始

本指南将帮助你在几分钟内开始使用 NotebookLM。

## 前置要求

要使用 NotebookLM，你需要：

- **Google 账号** - 免费的 Google 账号即可
- **网络连接** - NotebookLM 是基于 Web 的应用
- **支持的浏览器** - Chrome、Firefox、Safari 或 Edge

::: tip 可用性
NotebookLM 目前在全球大多数国家和地区可用。如果你所在的地区无法访问，请查看官方公告了解最新的可用性信息。
:::

## 第一步：访问 NotebookLM

1. 打开浏览器，访问 [notebooklm.google.com](https://notebooklm.google.com)
2. 使用你的 Google 账号登录
3. 首次访问时，会看到欢迎页面和简短介绍

## 第二步：创建你的第一个笔记本

笔记本（Notebook）是 NotebookLM 中的基本组织单位，类似于一个项目或主题文件夹。

1. 点击 **"新建笔记本"** 或 **"New Notebook"** 按钮
2. 为你的笔记本起一个描述性的名称
   - 例如：`研究项目`、`课程笔记`、`工作文档`
3. 点击创建

::: details 笔记本命名建议
- 使用清晰、描述性的名称
- 按主题或项目组织
- 例如：`机器学习论文集`、`市场分析报告`、`历史课程资料`
:::

## 第三步：添加来源文档

来源（Sources）是你想要 NotebookLM 分析的文档。

### 上传文档

NotebookLM 支持多种文档格式：

1. **从计算机上传**
   - 点击 **"上传"** 按钮
   - 支持格式：PDF、TXT、Markdown
   - 每个文件最大 500,000 字

2. **从 Google Drive 添加**
   - 点击 **"Google 文档"** 或 **"Google 幻灯片"**
   - 选择你的文档
   - NotebookLM 会自动同步更新

3. **添加网页链接**
   - 点击 **"网页"** 或 **"Web URL"**
   - 粘贴网页链接
   - NotebookLM 会提取网页内容

4. **粘贴文本**
   - 直接复制粘贴文本内容
   - 适合快速添加简短材料

::: warning 限制
- 每个笔记本最多 50 个来源
- 单个文件不超过 500,000 字
- 某些受保护的网页可能无法访问
:::

### 示例：添加第一个文档

假设你想分析一篇学术论文：

1. 准备好 PDF 格式的论文
2. 点击 **"上传"** 按钮
3. 选择你的 PDF 文件
4. 等待上传和处理（通常需要几秒到几分钟）
5. 文档处理完成后会出现在来源列表中

## 第四步：开始提问

现在你可以向 NotebookLM 提问了！

### 基础提问

在对话框中输入你的问题，例如：

- `这篇论文的主要观点是什么？`
- `总结一下关键发现`
- `作者使用了什么研究方法？`
- `这个概念的定义是什么？`

### NotebookLM 的回答特点

- **基于你的文档** - 所有回答都基于你上传的来源
- **引用来源** - 每个回答都会标注引用的来源
- **可追溯** - 点击引用可以查看原文
- **准确性** - 不会编造不在文档中的信息

::: tip 提问技巧
- 从简单的问题开始，逐步深入
- 可以要求不同格式的输出（列表、表格、时间线等）
- 如果回答不理想，可以换个方式重新提问
- 可以在对话中追问和深化
:::

## 第五步：使用 AI 功能

NotebookLM 提供多种 AI 辅助功能：

### 自动生成摘要

1. 选择一个或多个来源
2. 点击 **"生成摘要"** 或相关按钮
3. AI 会生成关键要点和概述

### 创建学习指南

1. 点击 **"学习指南"** 或 **"Study Guide"**
2. NotebookLM 会生成：
   - 关键术语和定义
   - 重要概念
   - 复习问题
   - 学习重点

### 生成音频概述

::: tip 新功能
音频概述是 NotebookLM 的特色功能！
:::

1. 点击 **"音频概述"** 或 **"Audio Overview"**
2. NotebookLM 会生成播客式的对话
3. 两个 AI 主持人讨论你的文档内容
4. 支持多种语言
5. 可以下载音频文件

## 第六步：组织和管理

### 创建笔记

除了 AI 生成的内容，你还可以：

1. 手动创建笔记
2. 保存重要的 AI 回答
3. 添加自己的想法和评论
4. 整理和分类信息

### 共享和协作

1. 点击 **"共享"** 按钮
2. 输入协作者的邮箱地址
3. 设置权限（查看或编辑）
4. 发送邀请

## 常见问题

### 为什么我的文档处理很慢？

- 大型文档（接近 500,000 字）需要更长时间
- 网络速度会影响上传时间
- 高峰时段可能处理较慢

### NotebookLM 是否存储我的文档？

- 是的，文档存储在 Google 的服务器上
- 受到 Google 的隐私政策保护
- 你可以随时删除文档和笔记本

### 可以离线使用吗？

- 目前 NotebookLM 需要网络连接
- 离线功能可能在未来版本中推出

### 支持哪些语言？

- 界面支持多种语言
- AI 理解和生成支持主要语言
- 包括英语、中文、日语、韩语等
