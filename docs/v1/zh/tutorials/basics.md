# 基础操作教程

本教程将详细介绍 NotebookLM 的基础操作，帮助你熟练掌握日常使用技巧。

## 文档上传技巧

### 选择合适的文档格式

不同格式有不同的优势：

**PDF 文件：**

- ✅ 保留原始格式
- ✅ 图表和图像保留
- ⚠️ 扫描 PDF 可能识别不准确

**Google 文档：**

- ✅ 自动同步更新
- ✅ 团队协作方便
- ✅ 格式识别准确

**纯文本：**

- ✅ 上传速度快
- ✅ 兼容性好
- ⚠️ 无格式信息

### 优化文档质量

为了获得最佳效果：

1. **清理文档内容**
   - 删除无关的页眉页脚
   - 移除广告和噪音内容
   - 保留关键信息

2. **结构化内容**
   - 使用清晰的标题
   - 保持段落逻辑
   - 添加必要的说明

3. **处理大型文档**
   - 拆分超大文档（接近 500,000 字）
   - 按主题分割文档
   - 保持文档的完整性

## 有效提问技巧

### 基础提问模式

**开放式问题：**

```
这篇文档的主要内容是什么？
总结一下关键观点。
```

**封闭式问题：**

```
文档中提到的三个主要因素是什么？
作者的结论是什么？
```

**对比式问题：**

```
比较文档 A 和文档 B 的观点差异。
这两个理论有什么不同？
```

### 高级提问技巧

**指定输出格式：**

```
以列表形式总结要点
创建一个表格对比这些概念
生成一个时间线
```

**设定角色和视角：**

```
从学生的角度解释这个概念
以专家的视角分析这个问题
用简单的语言解释给初学者
```

**多步骤问题：**

```
首先总结主要观点，然后分析其优缺点，
最后给出实际应用建议。
```

::: tip 提问秘诀
如果第一次问答不满意，可以这样优化：

- "请更详细地解释..."
- "用更简单的语言说明..."
- "给出具体例子..."
- "从另一个角度分析..."
:::

## 管理来源文档

### 组织来源

**添加描述：**

- 为每个来源添加简短说明
- 标注文档的重要性
- 记录文档的关联关系

**使用标签：**

- 按主题分类
- 按优先级分类
- 按时间分类

### 选择特定来源

在提问时针对特定文档：

```
基于《论文A》，解释这个概念
只使用《报告B》和《报告C》来回答
排除《文档D》，分析其他来源
```

### 更新和维护

- **定期检查** - 确保来源是最新的
- **删除过时内容** - 移除不再需要的文档
- **补充新资料** - 持续添加相关内容
- **重新组织** - 根据需要调整结构

## 保存和整理笔记

### 创建有效笔记

**保存 AI 回答：**

1. 看到有价值的回答
2. 点击"保存为笔记"按钮
3. 添加标题和标签
4. 可选：添加自己的评论

**手动创建笔记：**

1. 点击"新建笔记"
2. 输入标题和内容
3. 可以链接到相关来源
4. 添加标签便于查找

### 笔记分类系统

建议使用以下分类方法：

**按类型分类：**

- 📝 摘要笔记
- 💡 重要见解
- ❓ 待解决问题
- ✅ 行动项

**按项目分类：**

- 研究项目 A
- 课程笔记
- 工作文档

**按优先级：**

- 🔴 高优先级
- 🟡 中优先级
- 🟢 低优先级

## 使用音频概述

### 何时使用音频概述

**最适合的场景：**

1. **首次了解内容**
   - 快速了解文档大意
   - 建立整体概念框架

2. **复习和巩固**
   - 通勤时间复习
   - 运动时听课
   - 做家务时学习

3. **理解复杂概念**
   - 通过对话形式更易理解
   - 不同角度的讨论
   - 重复强化记忆

**不太适合的场景：**

- 需要精确引用时
- 需要查看具体数据时
- 需要深度分析时

### 音频概述使用技巧

1. **生成前准备**
   - 确保来源文档质量好
   - 检查文档是否完整
   - 考虑是否需要多个来源

2. **生成音频**
   - 点击"生成音频概述"
   - 等待处理（通常 2-5 分钟）
   - 预览音频内容

3. **使用音频**
   - 在线收听
   - 下载到设备
   - 配合笔记使用
   - 反复收听强化理解

::: tip 音频技巧
第一次听完后，可以带着问题再听一遍，这样能更好地理解和记忆。
:::

## 搜索和查找

### 站内搜索

NotebookLM 提供强大的搜索功能：

**搜索内容：**

- 来源文档内容
- 笔记内容
- 对话历史
- 保存的回答

**搜索技巧：**

```
使用引号搜索精确短语："机器学习"
使用 AND 组合关键词：人工智能 AND 应用
使用 OR 扩展搜索：教育 OR 培训
```

### 快速导航

- **最近访问** - 查看最近使用的笔记本
- **收藏夹** - 标记重要的笔记本
- **标签筛选** - 按标签快速筛选
- **时间排序** - 按创建或修改时间排序

## 导出和分享

### 导出笔记

**导出格式：**

- PDF - 保持格式
- Google 文档 - 便于编辑
- Markdown - 纯文本格式
- 纯文本 - 最简单格式

**导出选项：**

- 导出单个笔记
- 导出整个笔记本
- 导出选定的笔记
- 包含或排除来源文档

### 分享笔记本

**分享步骤：**

1. 打开要分享的笔记本
2. 点击"分享"按钮
3. 输入协作者邮箱
4. 选择权限级别
5. 添加可选的消息
6. 发送邀请

**权限说明：**

- **查看** - 只能查看，不能修改
- **评论** - 可以添加评论
- **编辑** - 可以完全编辑

## 常见问题解决

### 文档上传失败

**可能原因和解决方法：**

1. **文件太大**
   - 拆分文档
   - 压缩文件
   - 删除不必要的图片

2. **格式不支持**
   - 转换为 PDF
   - 使用 Google 文档
   - 复制粘贴文本

3. **网络问题**
   - 检查网络连接
   - 尝试刷新页面
   - 稍后重试

### AI 回答不准确

**改进方法：**

1. **优化提问**
   - 更具体的问题
   - 提供更多上下文
   - 分步骤提问

2. **检查来源**
   - 确认文档是否相关
   - 检查文档质量
   - 添加补充资料

3. **重新提问**
   - 换个角度提问
   - 使用不同的关键词
   - 指定特定来源

### 音频生成失败

**常见问题：**

- 来源文档太少或太简短
- 网络连接中断
- 系统暂时繁忙

**解决方案：**

- 添加更多相关文档
- 确保网络稳定
- 稍后重试

## 效率提升技巧

### 键盘快捷键

虽然 NotebookLM 是 Web 应用，但仍支持一些快捷操作：

- **Ctrl/Cmd + K** - 快速搜索
- **Ctrl/Cmd + Enter** - 发送问题
- **Ctrl/Cmd + /** - 查看帮助

### 批量操作

- 同时选择多个来源进行分析
- 批量添加标签
- 批量导出笔记

### 模板和预设

创建常用的提问模板：

```
分析模板：
1. 总结主要内容
2. 列出关键要点
3. 分析优缺点
4. 提出建议

学习模板：
1. 生成学习指南
2. 创建复习问题
3. 制作思维导图
4. 生成音频概述
```
